BloodLink - Blood Bank Management System

1. Introduction

BloodLink is an educational project developed to demonstrate blood bank inventory management and blockchain-based traceability.

2. Information Collection

The current prototype stores blood unit information such as unit ID, blood group, component, collection date, expiry date and status.

3. Data Storage

Blood unit information is stored in a MongoDB database. The current development version uses a local database.

4. Blockchain

Blockchain integration is planned for recording blood unit traceability events. Personal and medical information should not be stored directly on the blockchain.

5. Data Security

This prototype does not yet provide production-grade authentication, encryption or role-based access control. It should only be used with synthetic demonstration data.

6. Medical Disclaimer

BloodLink is an educational prototype and is not a substitute for authorised blood bank systems, professional medical decisions or applicable healthcare regulations.

7. Future Improvements

Future versions may include secure user accounts, access permissions, audit logs and additional data protection measures.

8. Contact

For project-related questions, contact the project development team.
